# ADR-001: Стандартный net/http

Статус: принято

## Контекст

Шлюз должен предоставлять доступ к жизненному циклу HTTP и сохранять корректную потоковую передачу.

## Решение

Использовать net/http и настроенный httputil.ReverseProxy с Rewrite, ModifyResponse, ErrorHandler, пулом буферов копирования и собственным транспортом попыток.

## Альтернативы

fasthttp, тяжёлый веб-фреймворк или ручной разбор и копирование всей семантики HTTP.

## Последствия

Сохраняются стандартные механизмы отмены, обработки заголовков и пула соединений. Маршрутизация и устойчивость реализуются явно. Пропускную способность нужно измерять, а не выводить из заявлений о фреймворке.
