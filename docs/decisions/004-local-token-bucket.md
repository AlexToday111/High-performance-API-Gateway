# ADR-004: Локальные корзины токенов

Статус: принято

## Контекст

Проект должен показывать компромиссы частоты, пополнения и параллелизма и работать без внешнего хранилища состояния.

## Решение

Реализовать корзины токенов на маршрут или непосредственного клиента с ограниченным хранилищем клиентов, очисткой по TTL и одним мьютексом ограничителя.

## Альтернативы

golang.org/x/time/rate, обязательный Redis на пути запроса, фиксированные временные окна.

## Последствия

Допуск локален и предсказуем. Каждая реплика имеет отдельный бюджет; ограничение по IP непосредственного клиента требует явных решений о доверии в окружении. Распределённые ограничения остаются вторым этапом.
