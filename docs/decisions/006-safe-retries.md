# ADR-006: Повторы только безопасных операций

Статус: принято

## Контекст

Повтор переданной операции изменения может дублировать побочные эффекты; неограниченная буферизация может исчерпать память.

## Решение

Повторять GET/HEAD/OPTIONS в пределах лимитов тела, числа попыток, задержки и общего срока. Предпочитать доступный сервер, который ещё не использовался. Никогда не повторять после отправки байтов ответа.

## Альтернативы

Повторять любой метод с ключом идемпотентности или буферизовать любое тело.

## Последствия

Успешность может вырасти ценой числа попыток, CPU и задержки. Осторожные внутренние правила повтора стандартного транспорта продолжают действовать. Повторы операций изменения с учётом приложения требуют отдельного последующего проектирования.
