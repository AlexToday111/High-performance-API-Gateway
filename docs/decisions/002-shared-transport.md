# ADR-002: Общий HTTP-транспорт

Статус: принято

## Контекст

Создание клиента или транспорта на каждый запрос уничтожает повторное использование соединений и делает ограничения ресурсов неэффективными.

## Решение

Создать один настраиваемый http.Transport на процесс шлюза, общий для попыток проксирования и ограниченных проверок здоровья. Отключить выбор прокси через окружение.

## Альтернативы

Транспорт на каждый запрос или отдельный транспорт на каждый сервер.

## Последствия

Пул сокращает затраты на соединения и TLS, централизует ограничения. Проверки здоровья и рабочий трафик разделяют лимиты; тайм-ауты проверок ограничивают конкуренцию. Изменение глобального транспорта требует перезапуска.
