# ADR-003: Неизменяемые снимки маршрутов

Статус: принято

## Контекст

Параллельные запросы не должны видеть частично применённую перезагрузку или изменять опубликованную конфигурацию.

## Решение

Копировать и проверять конфигурацию, строить новое префиксное дерево и список маршрутов, затем атомарно публиковать один снимок. Сохранять состояние неизменённых маршрутов под отдельным мьютексом перезагрузки.

## Альтернативы

Изменение общей карты под глобальным RWMutex; отдельные изменения на месте.

## Последствия

Читатели безопасно удерживают старые снимки. Изменённые маршруты сбрасывают состояние устойчивости и допуска; старые снимки сохраняются до завершения активных запросов. Глобальные настройки меняются только с перезапуском.
